# PlayHub game

## Architecture Overview

PlayHub is an iOS app built with **SwiftUI** using an **MVVM-style architecture**.

- **Models** – store game, player, score, and quiz data
- **Views** – SwiftUI screens
- **ViewModels** – handle game logic and UI state
- **Services** – manage storage, API calls, location, and notifications

## Features
- There are 3 games: Tap Frenzy, Light It Up, Quiz Rush
- Multiple player profiles
- Score and game history tracking
- Player statistics using Swift Charts
- Game locations using MapKit and Core Location
- Quiz questions from an online Trivia API
- Local notifications. reminders
- Local data storage using UserDefaults

## Known Limitations
- Data is stored only on the device.
- No login, cloud sync, or online leaderboard.
- Only three games are currently available.
